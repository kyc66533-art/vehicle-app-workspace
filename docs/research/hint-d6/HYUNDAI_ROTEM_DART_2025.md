## 0. 읽는 방법과 검증 기준

1. **원문과 해석을 분리**했다. 표의 요약·우선순위·활용 가능성은 분석자 판단이며 회사의 확약이 아니다. 원문 문장은 확보한 HTML의 문장·표제를 그대로 인용한다. 오탈자·띄어쓰기를 임의 교정하지 않는다.
2. 표에는 문장이 없으므로 재무 수치와 연구개발비는 **PDF 표의 행 원문**을 그대로 인용했다. 행의 값 순서는 제27기(2025)·제26기(2024)·제25기(2023)다. 원문에 없는 서술문을 만들어 넣지 않았다.
3. 요약은 각 행 최대 세 줄로 제한했다. 정확성 때문에 긴 원문 인용은 생략·의역하지 않았다.
4. 페이지는 공식 PDF 하단의 **인쇄 페이지 p.** 기준이다. PDF는 목차 네 면을 포함해 총 322면이며, 파일의 물리 페이지는 인쇄 페이지에 4를 더한 값이다. 예: p.37 = PDF 뷰어 41/322. HTML 자체에는 고정 페이지가 없다.
5. 본문의 “현재·진행 중”은 **해당 보고서의 보고 시점**이다. 조사일 현재까지 유지됨을 보증하지 않는다. 외부 시장 전망·“유일·독보적” 표현은 회사의 보고 또는 회사가 재인용한 자료이지 이번 조사에서 독립 검증한 사실이 아니다.
6. 금액은 원문 단위(억원·백만원·천원)를 유지한다. 기간 손익은 해당 연도 1.1~12.31, 잔액은 연말 기준으로 구분한다. 지식재산권처럼 원문 기준일이 불명확한 경우 억지로 연말에 맞추지 않는다.

## 6. 현대로템이 잘하는 것 후보 3개와 선별 평가

평가 표시는 **높음·중간·확인 불가**의 정성 판단이다. “현대로템만의”는 경쟁사에 전혀 없는 세계 유일 기술이 아니라, 현대로템이 실제 보유·수행한 것으로 원문에서 확인되는 기술·자산인지를 우선 평가한다. 독점성과 권리 독립성은 별도 검증한다.

### 후보 A. 철도 핵심 전장품·완성차 통합 및 유지보수 수행 기반

**선정 원문:** 「레일솔루션 부문은 국내외 전동차, 고속전철, 경전철, 디젤동차, 기관차 및 객/화차 등 다양한 차종의 철도차량을 공급해 오고 있으며, 철도차량의 핵심 전장품을 독자기술로 국산화하여 열차종합제어관리장치, 견인전동기, 추진제어장치, 보조전원장치 등을 생산하고 있습니다.」

**출처:** II-2 가. 주요제품 / 레일솔루션, p.14 [S2]. 고객·사업 수행 범위의 보강 근거: II-7 라. 6) 회사의 경쟁상의 강점과 단점 ② 레일솔루션, p.34 [S4].

- **실질적 기술·자산인가: 높음.** 독자기술로 국산화한 제어·구동·전원 장치 생산이라는 구체성이 있다. 다만 원천기술의 전면적 단독 소유·경쟁사 대비 성능 우위는 자료에서 확인 불가.
- **현재 보유 역량인가: 높음(보고서 기준).** “생산하고 있습니다”, “공급해 오고 있으며”와 누적 수주 실적이 근거다. CBM·DAS는 별개의 개발 중 역량이다.
- **새로운 사업에 활용 가능한가: 높음, 조건부.** 장치 설계 이해와 유지보수 수행 기반을 결합할 잠재력이 있다. 고객 동의·운영 데이터·현장 검증권이 확보돼야 한다.
- **시장 성장과 연결되는가: 높음, 조건부.** 보고서가 제시한 철도 교체·유지보수와 디지털화 방향에 연결된다. 세계 철도 전체 성장률을 당사 디지털 사업 성장률로 대입하지 않는다.
- **AI·디지털 트윈 결합 가능성: 높음(가설).** 물리 모델·AI 정비 개발 방향은 C5에서 확인된다. 실제 디지털 트윈 보유·완성도·예측 정확도는 자료에서 확인 불가.
- **기존 사업:** 철도차량·핵심 전장품 공급, E&M, 운영·유지보수.
- **새로운 사업 기회 영역(미확정):** 운영사 문제를 검증한 뒤 정비·생애주기 최적화의 추가 가치 영역을 탐색. 기존 CBM 개발의 단순 재명명을 신사업으로 취급하지 않는다.
- **한계:** 대형 해외 경쟁사 존재, 공공조달·안전 인증, 데이터 거버넌스 제약. 당사 매출로 연결되는 구매 주체·성과기준을 별도 확인해야 한다.

- **기존 사업:** K2 등 전차 양산·수출, 성능개량·정비·기술지원.
- **새로운 사업 기회 영역(미확정):** 기존 납품 이후 새로 지불할 가치가 있는 운용·지원 문제를 찾는 영역. 기존 정비 계약 자체를 신사업으로 포장하지 않는다.

- **기존 사업:** 프레스·운반설비·제철 EPC, 생산 엔지니어링, 무인항만로봇 공급.
- **새로운 사업 기회 영역(미확정):** 제조·물류 경계의 운영 개선과 지속 지원에서 신규 구매 가치가 있는지 탐색. 기존 설비 공급의 디지털 이름 변경은 제외한다.
- **한계:** 시스템 통합 책임·안전·현장 튜닝·수주 편중, 경쟁 솔루션 대비 차별성. 수소 밸류체인 기술 개발을 전부 이미 보유한 기술로 묶지 않는다.

## 7. 신사업 활용 강점 우선순위

이 순위는 **신사업 탐색에서 우선 검증할 순서**이지 기업가치·투자수익률·기존 사업의 우열 순위가 아니다. 공식 원문으로 확인되는 보유 역량, 고객 접점, 인접 확장 가능성, 검증 접근성을 중심으로 판단했으며 AI 친화성만으로 선별하지 않았다.

1. **후보 A: 철도 핵심 전장품·완성차 통합·유지보수 기반.** 보유 기술과 납품·정비 실적이 함께 확인된다. 물리 모델·AI 개발 방향과도 접점이 있다. 단, 운영사 데이터 협약과 실증 접근이 확보되지 않으면 디지털 확장 우선순위를 낮춘다.
2. **후보 C: 플랜트·항만·물류 엔지니어링 통합.** 현장 공급·시운전 경험과 다양한 고객 이력이 강점이다. 공정·물류 문제의 경제적 손실을 검증하기 좋지만, 반복 수익 구조와 데이터/현장 접근성은 확인해야 한다. 고객 검증이 더 쉬우면 A보다 먼저 탐색할 수 있다.
3. **후보 B: 전차 개발·양산·후속지원.** 기존 사업의 사업성 근거는 강하며 AI 접점이 낮다고 제외하지 않는다. 다만 신규 접근 주체 입장에서는 보안·수출통제·정부 조달과 긴 검증주기가 부담이어서 탐색 순위는 뒤에 둔다. 비디지털 후속지원의 실제 수요가 확보되면 순위를 높일 수 있다.

**별도 관찰: 수소 인프라.** 연간 수소추출기 생산능력과 공급 이력은 확인되지만 가동률·프로젝트 경제성·보조금 의존도·차세대 수전해 등 기술 완료 수준이 불명확하다. 상위 후보에서 제외한 이유는 AI 관련성 부족이 아니라 독립 사업성 검증 부족이다.

## 8. 추가 검증이 필요한 사항

### 8.1 원문 내 표현·기준일 문제

- **특허 기준일:** p.24의 “당분기말”이 정확히 어느 분기 말인지 회사 공시 담당자 또는 원자료로 확인. 특허·디자인의 건수는 존재 사실과 독점성·가치가 다르다.
- **수소트램 수량:** 동일 보고서에서 p.29는 “수소트램 34량”, p.35는 “수소트램 34편성”으로 서술한다. 계약 공시와 편성당 차량 구성으로 검증 전, 총차량수로 환산하거나 두 단위를 통일하지 않는다.
- **시장규모 범위:** p.32의 세계 철도시장 전망은 SCI Verkehr 2024 자료의 회사 재인용이다. pp.29~30의 “매년 약 20억 달러” 서술 등과 모집단·범위를 확인하기 전 혼합 계산하지 않는다. 최신 시장조사와 정의·환율·기준연도를 대조해야 한다.
- **비교우위:** “국내 유일”, “독보적”, “경쟁 혹은 우위 관계에 있는 업체가 없음”의 비교 대상·제품 범위·시점, 공동개발·협력사 기여를 외부 자료로 확인한다.

### 8.2 후보별 사업 검증

- **A/철도:** 핵심 장치별 IP·라이선스·설계권, 운영사와 데이터 사용계약, 센서·고장·정비 라벨 품질, CBM·DAS 개발 단계와 상용 실적. 안전·사이버보안 인증과 검증 노선·차량 확보. 허위 경보·미탐·정비시간·다운타임의 비교 기준.
- **B/방산:** 후속지원에서 새로 필요한 문제, 구매 예산·발주 주체, 국외 현지화·수출통제·보안 요구, 데이터 비식별화·외부 공유 가능 범위. 수익성 있는 비디지털 서비스 기회도 병행 검증.
- **C/플랜트:** 실제 항만·공장 가동 KPI, 무인항만로봇의 공급 범위와 제어 SW 권리, 물류관제·AGV 과제 완료 여부, 현장별 튜닝·설치·유지비, 타사 대체 가능성, 반복 판매·지원 계약 실적.
- **수소 관찰:** 실제 생산·수주·판매·가동률, 수소 가격·전력비·이용률·보조금 가정별 경제성, 법령·안전·운영 인허가와 차세대 기술의 준비도.

### 8.3 공통 검증 게이트

1. 고객이 겪는 손실과 현재 해결 방식을 실제 운영자·정비자·구매 담당자로 나누어 확인한다. 보고서의 성장 서술만으로 수요를 확정하지 않는다.
2. 데이터 권리·실물 접근·IP·안전 책임을 확정한 뒤 기술 검증 범위를 정한다. “납품 실적 → 데이터 독점 → AI 우위”라는 비약을 금지한다.
3. 현금흐름·계약부채/선수금·운전자본·보증·설비투자·부문 손익을 추가 검토한다. 요약재무정보의 총자산·영업이익을 신사업 가용예산으로 사용하지 않는다.
4. 경쟁사와 기존 제품을 조사해 기존 사업·개발 과제와 실질적으로 다른 신규 지불 가치를 확인한다. 기술을 붙이는 것과 새로운 사업을 만드는 것은 다르다.
5. 그 후에만 최종 신사업 후보와 최소 실증 목표를 설계한다. 이 문서에서는 최종 아이디어나 IR 덱을 확정하지 않는다.

## 9. GitHub 연결·파일 보호 및 업로드 상태

- 브라우저에서 로그인 계정 kyc66533-art, 비공개 저장소 kyc66533-art/vehicle-app-workspace와 main 접근을 실제 확인했다. 별도 로그인 요청은 필요하지 않았다.
- 기존 docs/research/ASIDE_RESEARCH.md는 열람만 했고 변경하지 않았다. 지정 경로는 확인 당시 main에서 “404 - page not found / 해당 경로가 없음”으로 확인했다.
- 이 문서는 지정 경로에 신규 생성할 내용이다. 기존 차량 앱 코드·문서·설정은 수정하지 않았다.
- **Git 절차의 사용자 승인 예외:** 이 PC의 허용된 작업 영역에서 Git 실행 파일과 로컬 체크아웃을 찾지 못했고 git status·git diff --name-only 실행은 “git 명령을 찾을 수 없음”으로 실패했다. 이를 보고한 뒤 사용자가 이번 작업에 한해 “웹 단일 파일 커밋 승인”을 선택했다.
- **승인된 반영 방식:** 로컬 Git 검사·스테이징·push 대신 GitHub 웹에서 지정 파일 하나만 main에 신규 커밋한다. 다른 파일을 수정·삭제·이동하지 않는다. 신규 생성 직전에도 대상 경로 부재를 다시 확인했다.
- **검증 방식:** 반영 후 GitHub 커밋의 변경 파일 목록과 main의 파일 원문을 다시 읽어 대조한다. 업로드 결과·파일 URL·전체 커밋 SHA는 별도 최종 보고로 제공한다. 자기참조를 피하기 위해 이 문서 안에 자신의 커밋 SHA를 기입하지 않는다.
