## 기존 코드가 제공하는 독립 경로

`문제 목록 → 선택한 한 건 → AI로 쉽게 설명 → 새로 설명 생성 → 실제 결과 → 이 설명 음성으로 듣기`입니다.

- `PortableAiActivity`는 Gleo를 사용하지 않습니다. 기존 Firebase 로그인·세션 갱신·Keystore 기기 등록·동의를 재사용합니다. 새 모델 결과의 TTS는 사용자가 명시적으로 누릅니다.
- `PortableAiClient.explain(payload,fresh=true)`는 모델/남은 한도/UNKNOWN을 인증 조회하고 기존 `/v2/issues/explanations`로 요청합니다. pending을 먼저 암호화 저장하고 동일 요청의 불확실 상태를 새 요청으로 재전송하지 않습니다.
- `fresh=false` 및 기존 설명 보기 경로는 검증된 캐시만 읽습니다. 새 설명 실패는 기존 성공 설명을 지우지 않습니다. 재시작 후에도 기록별·내용 버전별 캐시를 유지합니다.
- payload는 기존 승인된 `contract/source/category/situation` 계약이며, 사용자 정보 본문은 선택한 증상 종류와 문장뿐입니다. 작성자·메모·ID·발견시각·위치·Vehicle SDK 값·다른 기록은 보내지 않습니다. 입력란에서 개인정보를 빼도 원본 SQLite 기록은 바뀌지 않습니다.
- Worker의 `portable-issue.ts`는 같은 Gemini 모델과 Secret을 사용하고, 실제 HTTP 응답/finishReason/JSON/evidence/수치/조건부 원인 설명을 확인한 뒤 MODEL 봉투를 만듭니다. 고장·수리 완료·운행 안전 확정을 제한합니다. 정규식 검사만으로 완전한 안전성을 보장한다고 주장하지 않습니다.
- `GleoIssueAnalysis`는 별도 외부 Action용 어댑터입니다. 일반 앱 요청과 인증/캐시는 공유하되 이번 실행 경로에는 관여하지 않습니다. Gleo 7초 제한을 일반 앱 Gemini 요청에 적용하지 않습니다. 기존 Worker 공급자 제한12초와 앱 통신 제한을 유지합니다.

## 비용 근거

이번에 [Gemini3.5 Flash-Lite 공식 모델](https://aistudio.google.com/docs/models/gemini-3.5-flash-lite)과 [공식 Standard 가격](https://aistudio.google.com/docs/pricing#gemini-3.5-flash-lite)을 직접 확인했습니다. 텍스트 입력 USD0.30/백만 토큰, 출력 USD2.50/백만 토큰입니다. 이전 문서에서 함께 언급한 USD0.15/1.25는 Batch 가격으로, 이번 단발 Standard 호출에 적용하지 않습니다.

기존 요청 봉투8192바이트와 출력1024토큰 제한에 대해 입력을16384토큰으로 넉넉히 잡은 계획값은 `16384 × 0.30 / 1,000,000 + 1024 × 2.50 / 1,000,000 = USD0.0074752`입니다. 원장의1회 예약은 USD0.01이며 기존 월 USD3 예약 예산 안에서 사용합니다. 이는 실제 청구 상한이 아니고, 세금/Cloudflare/다른 키 사용은 포함하지 않습니다. 계정 무료 할당량이면 Gemini 비용이 없을 수 있으나 무료를 보장하지 않습니다.
