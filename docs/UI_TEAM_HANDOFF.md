## AI 계약

기록 상세의 진입은 네트워크 요청을 자동 시작하지 않습니다. ‘기존 AI 설명 보기’는 로컬 AES 저장만 읽고, ‘새로 설명 생성’만 명시적으로 요청합니다. 성공 결과가 있으면 추가 생성 확인을 거칩니다. busy/UNKNOWN은 새 요청으로 우회하지 않습니다. PortableAiClient.explain(payload,fresh=false)는 저장 결과 우선이며 fresh=true가 명시적 생성입니다.

기존 성공 결과와 최근 실패를 별도로 표시합니다. 내용 버전 변경 전 설명은 과거임을 표시합니다. 구버전의 opaque job hash에 기록 ID 정보가 없고 이미 수정된 경우 자동 귀속하지 않습니다. 재로그인/동의 철회 정책과 운전자 전환은 별개입니다. 로그아웃/철회는 기존 보안 정책상 AI 사본을 지울 수 있지만 차량 기록은 지우지 않습니다.

UI팀 동시 수정 주의: PortableAiActivity.kt/PortableAiClient.kt/IssueAiChecks.kt가 이번 변경 대상입니다. MainActivity·Repository·Vehicle SDK·SQLite 스키마는 이번에 재설계하지 않습니다. 새 화면은 CarSafetyGate ALLOWED를 매 동작 재검사하고, 화면 재생성으로 모델/SDK를 재호출하지 않습니다. 앱의 일반·validation applicationId를 유지합니다.

자동 검사 결과는 사용자 사용성 시험이나 실차 검증을 대신하지 않습니다. 60대 이상 사용자, TalkBack/rotary, 전체 화면 변형은 별도 공동 검수 대상입니다.
