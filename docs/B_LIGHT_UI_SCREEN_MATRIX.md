# B안 라이트 · 화면과 기능 대조

기준: Aside `CARITDA_REDESIGN_20261111_PROTOTYPE.html`, DESIGN/AUDIT/CODEX. 연구 원본은 변경하지 않는다. 원래 Main 22개 화면과 Portable AI 2모드를 아래에서 전부 대응한다. 새 인계 큐는 별도로 추가했다. 계측 fixture와 일반 앱의 사람이 직접 확인한 결과는 구분한다. 최종 수치·캡처·제한은 [검증 기록](B_LIGHT_UI_ACCEPTANCE.md)에 기록한다.

## 삭제·통합·이동한 행동의 대응

| 기존 행동 | 새 실제 경로/의미 |
| --- | --- |
| 홈의 `nav_HOME` | 비대화형 브랜드; 하위 화면 `nav_HOME`은 그대로 앱 홈 |
| 전역 `nav_ISSUES` | 홈→기록 전체 보기(`all_issues`) |
| 전역 `nav_VEHICLE` | 홈→차량 상태 보기(`vehicle_health`) |
| 전역 `menu`/닫기 | 홈→설정·도움말(`settings_help`), 하위는 `back`/`nav_HOME` |
| 메뉴의 `all_issues` 복제 | 홈 단일 진입, 하위 이전으로 돌아감 |
| 메뉴 `my_issues` | 기록→내가 작성한 기록(`filter_MINE`) |
| 메뉴 `auto_snapshots` | 차량→조회 시점·변경 이력 보기 |
| 홈/빠른 전환의 `manage_drivers` | 설정→운전자 등록·이름 관리 |
| 빠른 전환의 `add_driver` | 설정→운전자 등록·이름 관리→추가(등록0명일 때만 빠른 화면에서도 등록) |
| 운전자 전환 취소 `cancel_driver` | 이전/홈; 후보 선택은 확정하지 않음 |
| `reset_conditions`+빈 결과 `show_all_records` | 조건이 있을 때 `reset_conditions` 한 개로 검색/필터 초기화 |
| `all_summary` | 기록→상담용 전체 요약 펼치기→전체 요약 |
| 상세의 `issue_summary` | 기록·점검 관리 펼치기→정비 상담용 기록 |
| `change_status` | 기록·점검 관리 펼치기→네 수동 상태 선택 |
| `recurrence` | 기록·점검 관리 펼치기→다시 발생한 증상 |
| `speak_issue` | 기록·점검 관리 펼치기→문제 내용 듣기(기존600자 범위, 전체 AI TTS와 별도) |
| `edit_issue`/`delete_issue` | 작성 내용 관리 펼치기→수정/삭제, 영구 작성자 ID guard 유지 |
| 상세 `add_note` | 읽음 완료/본인 기록이면 주요 행동; 미확인 타인 기록은 읽음이 우선이며 관리 아래 메모 유지 |
| 위치 `location_history`/more | 위치 자세히 보기→위치 연결 이력/더 보기 |
| 차량 항목별 기술 설명 | 기타 차량 정보→출처·수신 상태 자세히→신호별 원문 |
| 차량의 `unavailable` | 기타 차량 정보→출처·수신 상태 자세히에 미지원 연료 등20종 상태를 통합; 미수신은0으로 표시하지 않음 |
| 작성 복구의 `recover_record_route` | 초안 없음 안내와 공통 홈→기록 전체 보기; 기존 기록 복구/삭제를 자동 수행하지 않음 |
| `load_details` | 차량 기술 상세 또는 설정→지원·수신 기술 정보 |
| `analysis_ai` | 기술 정보→전송 없는 구조 요약 도구; 실제 SOC AI는 그래프의 별도 `portable_ai` |
| 도움 `help_contents`/`close_help`/`close_menu` | 상단 이전/홈; 목차는 사용법의 상황별 사용법 |
| 다시 보기 `close_guide` | 중복 본문 닫기 제거, 상단 이전으로 복귀; 신규 설치의 시작/나중에는 유지 |
| 테마 순환 `theme` | 설정→밝게/어둡게/자동 명시 선택; 자동 선택 시 기기 설정을 따른다는 안내 |
| 음성 패널의 비활성 `voice_cancel`/빈 인식 문장 | 대기 중 숨김, 인식 중 취소·문장·상태는 표시; 취소/FSM/late guard 그대로 |
| `portable_withdraw`/status/logout | AI→계정·이용 정보 펼치기; 철회/사용량/로그아웃 의미 보존 |
| 기존 AI 보기 `portable_view_saved` | 검증된 현재 버전 캐시를 결과 영역에 바로 표시; 출처와 새 요청 없음 표시, 복구 조건의 기존 보기 handler도 유지 |
| AI 화면 내 차량 원시 정보 | 기기에서만 보는 차량 참고→함께 볼 차량 정보 자세히; payload는 불변 |

기존 `speak_consultation_`+issue.id는 문자열 보간으로만 바뀌었고 같은 runtime 태그/상담 전체 요약·600자 TTS handler를 유지한다. `back`은 새 공통 헤더의 실제 이전 버튼이다. 리터럴 태그 차분과 실제 생성 태그를 구분해 이동·삭제로 오인하지 않았다.

저장/저장하고 AI 설명은 저장 후 목적지가 달라 유지했다. 문제 원문 듣기와 AI 전체 듣기, 읽음/메모/네 상태/재발, SOC 자동 안내와 그래프 분석도 서로 다른 기능으로 유지했다. 삭제한 전역 탭의 숨은 더미 View는 없다. 예전 계측은 `BLightTestNavigation`을 통해 **실제 표시되는 새 버튼 경로**를 따라가며 기능을 호출한다.

## HTML B안과 Android의 대조 기준

| B안 페이지 | Android 대응 | 반영과 의도적 차이 |
| --- | --- | --- |
| home | HOME | 브랜드/설정, 운전자, 인계 강조,1.4:1; 최신 사용자 지시대로 정상 metric은 홈에서 제외 |
| health | VEHICLE | 주요 값/시각,두 영역/요약/상세; 유효 확인 항목이 있으면 수치보다 먼저 표시 |
| record | RECORD | 종류·상황·음성/선택 접기와 별도 저장 카드; 실제 STT·명시 commit 사용 |
| records | ISSUES | 검색/4필터/카드; 원본 상태 이름과 미확인 의미 보존 |
| detail | DETAIL | 원문/상태/주행동/AI/선택 연결/관리 접기; 실제 위치의 마지막 확인 시각 주의 보존 |
| ai | Portable AI | 요청/결과 두 영역,전체 듣기/전송 사본; 실제 최초 동의·계정/한도 문구는 시안보다 길어도 유지 |
| handover | HANDOVER | 운전자별 미확인 목록·명시 읽음, 상태/해결 분리 |
| settings | MENU/DRIVER_MANAGE | 이름 관리/테마/표시 설정/도움·개인정보, 추가·수정·보관 실제 서비스 |
| help | HELP | 세 역할 카드+접힌6주제, 실제 현재 기능으로 문구 수정 |

라이트/다크 색·카드18dp/24dp 여백·1.4:1·32/24/20/40sp를 공통화했다. 시안의 브라우저 도구·앱 밖 OS 모형은 제품에 넣지 않는다. 실제 앱의76dp 최소 터치 목표를 HTML64px보다 우선한다. 안전 제한·큰 글씨·짧은 창·키보드에서는 한 열/전체 스크롤을 사용한다. 시안 픽셀과 무조건 동일하다는 주장은 하지 않으며 실제 캡처와 계측 범위를 함께 제시한다.
