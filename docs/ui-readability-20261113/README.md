## 1. 왜 바꿨나

- 대상 사용자가 초보 운전자와 고령 운전자입니다.
- 화면에 글이 많고 글자가 작으며, "관측·수신·세션·인계·좌표" 같은 어려운 말이 많았습니다.
- 참고한 기준(공식 문서 원문은 열지 못하고 검색 요약으로만 확인): 차량용 터치 목표 크기 76dp, 본문 글자 크게, 한 화면 2줄 이내 설명, 단계 수 줄이기. (가정: 정확한 수치는 원문 확인 필요)

## 2. 코드에서 고친 곳 (주요 파일)

### 2-1. `ui/CaritdaDesign.kt` — 디자인 부품
- 글자 크기: `CaritdaTokens.BOOST=6` 추가. `text()`와 `action()`이 `크기 + BOOST`로 그립니다. → 모든 화면 글자 +6.
- 글자색: 밝은 테마의 본문/보조 글자를 검정(`#000000`) / 짙은 회색(`#33414C`)으로 변경.
- 눌림 표시: 버튼을 누르면 원래 배경 위에 반투명 색을 겹쳐서 **글자가 그대로 보이게** 했습니다. (흰 배경에 흰 글자가 되던 문제 해결)
- 새 아이콘: `SUN`, `MOON`, `AUTO`, `MIC`, `HELP`, `SHIELD`, `INFO` 등.
- 새 부품:
  - `accordion(title, summary, key, open, enabled, …)` — 큰 제목을 누르면 아래가 펼쳐지는 줄
  - `listRow(title, summary, key, …)` — 제목+한 줄 설명+화살표 목록 줄
  - `choiceTile(title, key, selected, …)` — 해/달/자동 같은 선택 타일

### 2-2. `ui/CaritdaPage.kt` — 앱 이름 표시
- 스크롤되는 본문 **바깥**에 "CARITDA" 글자를 왼쪽 아래 빈 공간에 한 개 고정했습니다. 화면을 옮겨도 같은 자리입니다.
- 눌리지 않고, 본문 옆 빈 공간이 충분할 때만 보입니다(좁은 창에서는 숨김).
- 현대 마크는 쓰지 않았습니다(상표·공식 파일 문제). 앱 이름 글자만입니다.

### 2-3. `MainActivity.kt` — 화면 구성과 문구
- 설정·도움말(`moreMenu`)을 **목록 줄**로 재구성: 운전자, 화면 보기, 음성 대화, 사용법, 처음 안내, AI와 개인정보, 앱 정보. (태그 `manage_drivers`, `vehicle_settings` 등 기존 이름 유지)
