- 미검증: 실제 OS 분할/회전/IME와 모든 대화상자 확대 조합, TalkBack 발화 순서·rotary 물리 입력, 시스템 고대비 설정/반사광·한글 물리 크기, 실제 사용자2~3명 과제, 실차 및 실제 주행 RESTRICTED. UNKNOWN 차단과 synthetic safety 검사는 실차 검증과 다릅니다.

- Debug APK이며 Release 서명·Release 실행·제출 APK 준비는 미완료입니다. 저장소 공개 전환/심사자 초대/서명키 게시를 수행하지 않았습니다.
- 향후 AttentionContent/상세에 검증된 판단·AI 설명을 통합할 위치만 준비했습니다. 자동 진단/회복/저SOC 안내/Gleo/폰 알림/상시 관측/차량 제어는 신규 구현하지 않았습니다.

## 직접 확인할 순서

1. 차량 아이콘 일반 CARITDA를 열고 홈에서 충전량·거리·시각을 확인합니다. 플라스크/[TEST] 앱과 구분합니다.

3. 증상 남기기에서 본인 이름을 명시 확정하고 증상·짧은 상황을 입력합니다. 필요하면 추가 정보에서 차량 정보 함께 저장을 선택합니다.
4. 저장 성공과 같은 기록 상세, 점검 상태/수정/상담·연결 차량 정보를 확인합니다. 본인 원문 삭제는 확인창 내용을 읽은 뒤 결정하세요.
